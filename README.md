# AI Resume Analyzer & Job Matcher

An upcoming AI-powered application designed to analyze resumes, compare candidate skills with job descriptions, and provide actionable career improvement suggestions.

## Project Status

🚧 Planned / In Progress

## Planned Features

- PDF resume upload and text extraction
- Resume analysis using AI
- Job description and resume comparison
- Skill matching and gap identification
- Resume improvement suggestions
- Job-match score and analysis dashboard
- Save analysis history

## Planned Technology Stack

- Python
- FastAPI
- Google Gemini API
- SQLite
- PyMuPDF
- HTML, CSS, JavaScript
- Chart.js

## How It Will Work

1. Upload a resume in PDF format.
2. Enter a target job description.
3. Extract resume content.
4. Analyze skills and experience using AI.
5. Compare the candidate's profile with job requirements.
6. Generate feedback and improvement suggestions.

## Learning Objectives

- AI API integration
- Backend development with FastAPI
- PDF processing
- Database management
- Building practical AI-powered applications
